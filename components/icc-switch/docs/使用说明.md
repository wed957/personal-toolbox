# ICC Switch 使用说明

## 快速开始

1. 下载 `release/ICC-Switch.exe`。
2. 双击启动，等待程序读取显示器和已安装的 ICC 配置。
3. 选择显示器与配置，点击“应用”。

程序不会自动修改配置。只有点击“应用”后，选中的 ICC 才会写入当前用户的显示器关联。

## 导入 ICC

点击“导入 ICC...”，选择 `.icc` 或 `.icm` 文件。导入完成后，程序会刷新配置列表；选择它并点击“应用”即可生效。

如果 Windows 拒绝安装文件，请确认文件扩展名正确、文件未损坏，并按系统提示使用具有足够权限的账户运行。

## 恢复默认

点击“恢复默认”会遍历所有活动显示器，设置系统自带的 `sRGB Color Space Profile.icm`。如果该配置不存在，程序会显示错误而不会修改显示器关联。

## 命令行

```powershell
# 查看活动显示器
.\icc-switch-cli.exe list

# 查看已安装 ICC
.\icc-switch-cli.exe profiles

# 按文件名切换当前用户的第 1 台显示器
.\icc-switch-cli.exe set "Display P3.icc"

# 切换指定显示器（编号从 1 开始）
.\icc-switch-cli.exe set "Display P3.icc" 2

# 从本地路径安装后切换
.\icc-switch-cli.exe install "D:\ICC\Display P3.icc" 1
```

命令行程序返回码为 `0` 表示成功，非 `0` 表示失败。执行 `.\icc-switch-cli.exe --help` 可查看参数说明。

## 常见问题

### 列表为空

点击“刷新”后重试。确认显示器处于活动状态，并检查 Windows 色彩管理中是否已经安装 ICC 配置。

### 切换后颜色没有立即变化

部分应用会缓存颜色配置。关闭并重新打开目标应用；需要时注销或重启 Windows 以让所有应用重新读取配置。

### 找不到某个 ICC 文件

`set` 可以接收已安装配置的文件名，也可以接收本地 `.icc` / `.icm` 路径。路径包含空格时请使用引号。

## 安全与权限

程序使用 Windows `mscms.dll` 提供的色彩管理接口，不联网、不上传 ICC 文件。导入第三方 ICC 前请确认其来源可信。
